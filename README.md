# Tourist Flow Forecasting — Tuscany, Italy

Machine learning pipeline to forecast monthly tourist spending across 
five Tuscan cities, developed as Bachelor Seminar Project 4 at the 
University of Luxembourg under the supervision of Prof. Giacomo Di Tollo.

## Overview
Tourists flows and spending patterns across Florence, Pisa, Siena, 
Arezzo, and Lucca are predicted using real-world economic transaction data.

## Dataset
- 335,000+ rows of Mastercard payment transaction records
- Source: Smart Region Toscana platform (proprietary — not published)
- Period: January 2019 — July 2024
- Coverage: 30+ countries of origin, 8 spending sectors (Hotels, Dining, 
  Transport, Apparel, and more)
- Includes the COVID-19 disruption period

## Models
- **ARIMA** — classical statistical baseline for time series forecasting
- **LSTM** — recurrent neural network capturing non-linear temporal dependencies

## Tech Stack
Python, pandas, NumPy, scikit-learn, Matplotlib, Jupyter

## Status
In active development — dataset is proprietary and cannot be published.
